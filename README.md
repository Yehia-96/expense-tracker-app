# Expense Tracker for iPhone

The phone half of a personal expense tracker. It signs in to the same account as the desktop
app and keeps the same data, synced through Supabase. Every row is private to its account
(row-level security); the key in js/api.js only names the project.

Open https://yehia-96.github.io/expense-tracker-app/ in Safari, then Share > Add to Home Screen.

Published from the desktop project's mobile/ folder by scripts/publish-mobile.ps1; edit it there.
